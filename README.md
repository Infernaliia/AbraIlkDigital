# AbraIlkDigital – Modern Business Website

A modern, responsive business website for **AbraIlkDigital**, a digital agency concept focused on helping businesses build and improve their online presence.

The website demonstrates frontend development skills using HTML5, CSS3 and JavaScript, with an emphasis on clean design, responsive layouts and interactive user experiences.

## Project Overview

**Project:** AbraIlkDigital  
**Type:** Digital Agency Website  
**Target Audience:** Small businesses and large corporations  
**Tagline:** Digital solutions built around real businesses.

### Main Services

- Web Development
- UI/UX Design
- Website Maintenance

## Features

- Responsive design for desktop, tablet and mobile.
- Modern business-focused layout.
- Dark and light theme toggle.
- Theme preference saved using Local Storage.
- Interactive mobile navigation menu.
- Smooth scroll-reveal animations.
- Animated buttons and service cards.
- Portfolio section featuring concept projects.
- Contact form with client-side validation.
- Accessible navigation and form labels.

## Technologies Used

| Technology | Purpose |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Infernaliia/AbraIlkDigital.git
```

Replace `https://github.com/Infernaliia/AbraIlkDigital.git` with your actual repository URL.

### 2. Open the project

Open the project folder in Visual Studio Code or another code editor.

### 3. Run the website

Open `index.html` in your browser.

For a better development experience, you can use the Live Server extension in Visual Studio Code.

## Design

The website uses a consistent visual identity built around the following colour palette:

| Colour | Hex Code | Usage |
|---|---|---|
| Midnight Navy | `#111827` | Primary dark colour |
| Warm White | `#F5F3EE` | Light backgrounds |
| Lime Green | `#A3E635` | Highlights and interactive elements |
| Slate | `#64748B` | Secondary text |

Typography uses Arial/Helvetica for a clean and readable appearance.

## Contact Form

The contact form currently includes client-side validation using JavaScript.

**Important:** The form is a frontend demonstration. It does not currently send messages to an email address or backend service.

A backend or form-handling service would be required to enable message delivery.
